Fase 1: Pengenalan Konsep VPS & Cloud

Penjelasan singkat pemahaman mengenai perbedaan layanan berikut:

Layanan Penjelasan Singkat
Shared Hosting Layanan hosting di mana satu server fisik digunakan bersama oleh banyak pengguna. Sumber daya (CPU, RAM) dibagi rata. Cocok untuk website berskala kecil karena biayanya murah.
Dedicated Server Layanan di mana satu server fisik disewa secara eksklusif oleh satu pengguna. Memberikan kontrol penuh dan performa maksimal karena sumber daya tidak dibagi dengan orang lain.
Amazon Lightsail Layanan VPS cloud dari AWS yang sangat mudah digunakan (beginner-friendly) dengan skema harga bulanan tetap (flat-rate). Sangat cocok untuk pemula dan project aplikasi web sederhana.
Amazon EC2 Layanan komputasi awan AWS yang sangat fleksibel dan dapat diskalakan sesuai kebutuhan (scalable). Pengguna memiliki kontrol penuh atas instans, jaringan, dan sistem operasi.
